CSCI 520, Assignment 1

William Zhao

================

Jello simulation using mass-spring system. The simulation includes gravity, spring forces, and collision detection.
Features:
- Mass-spring system for simulating the jello cube
- Collision with a user-defined plane (Extra Credit)
- User input to adjust the plane's position and orientation
- Left-click to apply an impulse to the jello cube (Extra Credit)

Controls:
ESC: exit application
v: switch wireframe/triangle mode
s: display structural springs on/off
h: display shear springs on/off
b: display bend springs on/off
space: save the current screen to a file, filename index increments automatically
p: pause on/off
z: camera zoom in
x: camera zoom out
right mouse button + move mouse: camera control
e: reset camera to default position
left mouse button: apply an impulse to the jello cube
